## 不具合が起きたときに

ご連絡の前に、次を確認していただけると原因の切り分けが早くなります。

### 1. エンジンの状態を見る

メニューの「エンジン」→「音声モデルの管理」から管理画面を開き、「エンジン」タブをご覧ください。使用中のチェックポイント、動作しているバックエンド、実行デバイスが表示されます。

### 2. 依存ライブラリを自己診断する

音声が合成できない、アクセント欄が 1 句しか出ない、取り込んだモデルが一覧に並ばない、といった症状は、Python 側の依存関係が原因のことがほとんどです。次のコマンドで、どの依存でつまずいているかを確認できます。

```
python engine/run_engine.py --diagnose
```

実行ファイル版をお使いの場合は次のとおりです。

```
irodori-voice-engine.exe --diagnose
```

### 3. ログを確認する

このページ右上の「ログフォルダを開く」ボタンから、エディタのログを開けます。エンジン側のログは、エンジンを起動したコンソールに出力されます。

ログには PC のユーザー名などのシステム情報が含まれる場合があります。共有される際はご確認ください。

## よくある原因

| 症状 | 確認すること |
| --- | --- |
| 話者一覧が空になる | エンジンが起動しているか（`http://127.0.0.1:50121/speakers` が応答するか） |
| 読みが崩れる、アクセント欄が 1 句しか出ない | `pyopenjtalk-plus` が導入されているか。`pyopenjtalk-dict` が上書きしていないか |
| 取り込んだモデルが選べない | 任意の追加依存が導入されているか。ONNX 形式は合成に使えません |
| キャプションを変えても声が変わらない | MeanFlow 版のチェックポイントを選んでいないか（条件付けが無効になります） |
| 合成が遅い | サンプリング回数の設定と、PyTorch が CPU 版か GPU 版か |
