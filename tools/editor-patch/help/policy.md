# ソフトウェアの利用規約

IRODORI-VOICE（以下「本ソフトウェア」）をお使いいただく前に、この規約をお読みください。本ソフトウェアを使用した時点で、この規約に同意したものとみなします。

## 本ソフトウェアについて

本ソフトウェアは、音声合成エンジン **IRODORI-VOICE Engine** と、**VOICEVOX エディター**を組み合わせて動かす読み上げソフトです。エンジンは Irodori-TTS を中心に、取り込んだ音声モデルも扱えます。

本ソフトウェアは個人が制作したものであり、**VOICEVOX の公式プロジェクトではありません**。VOICEVOX 公式へ本ソフトウェアに関するお問い合わせをしないでください。同様に、Irodori-TTS の作者、および各音声モデルの配布元へのお問い合わせもご遠慮ください。

## 音声の利用について

**本ソフトウェアは、合成した音声の利用条件を定めません。** 利用条件を決めるのは、その音声を出した音声モデルの配布元です。

- 音声モデルごとの規約は、ヘルプの「音声ライブラリの利用規約」でご確認ください。
- 参照音声を持たない話者（シードから作った話者）の声は、Irodori-TTS が学習した範囲から生成されたもので、特定の人物の声を再現するものではありません。
- 他人の声を参照音声として登録する場合は、その人の許諾を得てください。本ソフトウェアは許諾の有無を確認しません。

生成した音声に含まれる電子透かし（SilentCipher）は、Irodori-TTS の推論コードが付与するものです。取り除いての使用は想定していません。

## 禁止事項

次の目的で本ソフトウェアを使用しないでください。

- 法令に違反する行為、または犯罪行為に結びつく行為
- 特定の個人・団体を誹謗中傷し、名誉や信用を傷つける行為
- 本人の許諾なく、実在する人物の声を模倣した音声を公開・配布する行為
- 音声モデルの配布元が定める規約に違反する行為
- 合成した音声を、実在の人物が実際に発言したものとして提示する行為

## 通信について

本ソフトウェアのエンジンは `127.0.0.1` のみで待ち受け、外部へ通信しません。合成したテキストや音声が外部へ送信されることはありません。

ただし、次の場合は例外的に外部へ接続します。

- 初回の起動時、音声合成モデルが手元に無い場合に Hugging Face から取得します
- Style-Bert-VITS2 が読みの解析に使う言語モデルを、初回の合成時に取得します

いずれも取得後はローカルに保存され、以後は接続しません。
