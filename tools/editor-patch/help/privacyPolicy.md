# プライバシーポリシー

本ソフトウェアは、利用状況の収集を行いません。

- 読み上げたテキスト、合成した音声、作成した話者、登録した参照音声は、すべてお使いの PC 内にのみ保存されます。
- エンジンは `127.0.0.1` のみで待ち受けます。外部からの接続は受け付けず、外部へも送信しません。
- 操作ログや利用統計を送信する機能はありません。

## 外部へ接続する場合

次の場合に限り、外部のサーバーへ接続します。いずれも取得したファイルはローカルに保存され、以後は接続しません。

- 音声合成モデルが手元に無い場合、Hugging Face から取得します
- Style-Bert-VITS2 が読みの解析に使う言語モデルを、初回の合成時に取得します

これらを事前に取得しておけば、以後は完全にオフラインで動作します。
