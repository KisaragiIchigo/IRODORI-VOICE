# 使い方

## はじめに

IRODORI-VOICE は、音声合成エンジンと VOICEVOX エディターを組み合わせた読み上げソフトです。画面は VOICEVOX そのものですので、**VOICEVOX で覚えた操作、ユーザー辞書、台本ファイルはそのまま使えます**。

一方で、音声を作っている仕組みは VOICEVOX とは別のものです。そのため、調整できる項目に違いがあります。異なる点だけを先に押さえておくと、迷わずに済みます。

| | VOICEVOX | IRODORI-VOICE |
| --- | --- | --- |
| 話速・音量 | 調整できます | 調整できます |
| モーラごとの音高・長さ | 調整できます | **調整できません**（項目が無効になります） |
| イントネーション・音高の全体調整 | 調整できます | **調整できません** |
| 話し方の指定 | スタイルを選びます | スタイルを選びます（内部の仕組みが異なります） |
| 歌唱（ソング機能） | 使えます | **使えません**（切り替えボタンが出ません） |
| モーフィング | 使えます | **使えません** |

## 起動する

`start-voicevox-editor.bat` を実行してください。エディタが起動し、エンジンも一緒に立ち上がります。エンジンの起動には少し時間がかかります。話者一覧が空のままの場合は、エンジンの準備が終わるまでお待ちください。

エンジンだけを確認したい場合は `start-engine.bat` を実行し、ブラウザで `http://127.0.0.1:50121/speakers` を開いてください。話者の一覧が表示されれば正常に動作しています。

## 音声を作る

1. 画面上部から話者を選びます
2. テキスト欄に読ませたい文章を入力します
3. Enter キーまたは再生ボタンで音声が再生されます

初回の合成では、モデルの読み込みに時間がかかります。2 回目以降は速くなります。同じ話者・同じ文・同じ設定の合成結果はキャッシュされるため、聞き直しは即座に再生されます。

## 話者とスタイル

### 話者を増やす

メニューの「エンジン」→「音声モデルの管理」から管理画面を開きます。話者の作り方は 2 通りです。

**声を借りる** — 取り込んだ音声モデルの声を手本にして、Irodori-TTS の話者を作ります。声の同一性はモデル側から、抑揚と間の取り方は Irodori-TTS から受け継ぎます。作成には十数秒かかります。

**シードから** — 音声モデルを 1 つも持っていなくても話者を作れます。参照音声を持たない話者の声はシード値だけで決まるため、`0` から `2147483647` までの整数と名前を決めるだけで作成できます。同じ値からは必ず同じ声になりますので、気に入った声はその数字ごと残せます。

### スタイル

話者を「声を借りる」で作り、「喜怒哀楽のスタイルも作る」を有効にしておくと、24 種類のスタイルが一緒に作られます。あかるい・よろこび・やさしさ・あんど・じしん・からかい・かんがえ・かんたん・おどろき・てれ・ふあん・あせり・くるしげ・おこり・あきれ・ねむそう・よい・ちからづよく・おねがい・ろうどく・かなしみ・まじめ・ゆっくり・はやくち、の各種です。

スタイルの切り替えは、画面上部の話者選択から行います。VOICEVOX と同じ操作です。

### 表現の指定（注釈絵文字）

読み上げ文の先頭へ絵文字を書くと、その表現で読み上げます。スタイルもこの仕組みで動いています。

```
😊 今日はいい天気ですね。
🐢 ゆっくり読み上げます。
```

使える絵文字は決まっています。一覧に無い絵文字（😳 や 😨 など）は指示として扱われず、読み上げ対象の文字として音に混ざります。

本文に絵文字を書いた場合は、スタイル側の絵文字は付きません。書き手が明示した指示を優先します。

## 調整できるもの・できないもの

パラメータ欄のうち、**話速と音量だけが有効**です。音高、イントネーション、モーラごとの調整は無効になっています。

これは仕様です。Irodori-TTS はテキストから直接音声を作る仕組みで、モーラ単位の音高や長さを指定する入り口を持っていません。無理に後段で加工すると声質が崩れるため、エンジンが「対応していない」と申告し、エディタ側が該当する項目を自動的に無効化しています。

**読み方を変えたい場合**は、ユーザー辞書をお使いください（後述）。**抑揚を変えたい場合**は、スタイルの切り替え、注釈絵文字、句読点の打ち方で調整します。

## 読みの修正（ユーザー辞書）

メニューの「設定」→「読み方＆アクセント辞書」から、単語の読みを登録できます。登録した語は日本語解析へ反映されます。

ただし、Irodori-TTS の話者では**アクセントの指定は反映されません**。読み方（カナ）の指定のみが効きます。アクセントの入り口が無いためです。

## 文章の区切り方

句読点はそのまま「間」として音に影響します。読点を増やせば間が空き、感嘆符や疑問符は語尾の調子に影響します。

長い文章はエンジンが自動的に区間へ割って合成し、1 本の音声として返します。そのため 1 行が長くても末尾が切れることはありません。ただし合成時間は長さに比例して伸びます。

## 音声モデルを追加する

管理画面の「音声モデル」タブから、モデルファイルをドロップして取り込みます。1 つのファイルにモデル本体・設定・スタイルベクトルがまとまった形式に対応しています。

取り込んだモデルの話者は、そのままエディタの話者一覧に並びます。ONNX 形式のモデルは取り込めますが、合成には使用できません。

## 書き出し

VOICEVOX と同じです。メニューの「ファイル」から、1 行ずつの書き出し、繋げて書き出し、プロジェクトの保存が行えます。

## 合成を速くするには

管理画面の「エンジン」タブで設定を変更できます。

- **サンプリング回数**を減らすと速くなります。既定は 8 回です。40 回と比べておよそ 10 分の 1 の時間で合成できます。
- **MeanFlow 版のチェックポイント**へ切り替えると、さらに速くなります。ただしこの版では、キャプションによる喋り分けと参照音声への寄せ具合が効かなくなります。表現を優先する場合は標準版をお使いください。

## 対応していない機能

- **ソング機能（歌唱合成）** — このエンジンは歌唱に対応していません。ソングへの切り替えボタンは表示されません。
- **モーフィング** — 2 つの声を混ぜる機能には対応していません。
- **マルチエンジン** — 本ソフトウェアのエンジンと VOICEVOX 公式エンジンを同時に使う構成は確認していません。

## 設定とデータの保存先

| 内容 | 場所 |
| --- | --- |
| エンジンの設定 | `%APPDATA%\IRODORI-VOICE\settings.json` |
| 話者 | `%APPDATA%\IRODORI-VOICE\voices\` |
| ユーザー辞書 | `%APPDATA%\IRODORI-VOICE\dict\` |
| 音声モデル | `%APPDATA%\IRODORI-VOICE\` の下 |
| キャッシュ | `%LOCALAPPDATA%\IRODORI-VOICE\cache\` |

エディタ自身の設定は、VOICEVOX とは別の場所に保存されます。既に VOICEVOX をお使いの場合でも、設定が混ざることはありません。
